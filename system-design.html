00 · Introducción

Design System
Inhabi

Sistema de diseño normalizado a partir del sitio original. Consolida colores, tipografía, botones, tarjetas, formularios y componentes reutilizables en tokens CSS y clases utilitarias. Todas las clases llevan el prefijo del sistema y funcionan tanto en superficies oscuras como claras.

01 · Fundación

Tokens de diseño

Variables globales que alimentan todos los componentes. Cámbialas y todo el sistema se adapta automáticamente.

Espaciado fluido

Se adaptan al viewport con clamp(), sin breakpoints duros.

/* Espaciado */
--gutter:    clamp(20px, 4vw, 56px);
--section-y: clamp(72px, 10vw, 140px);
--max-w:     1400px;

Radios

--r-pill: 999px;  /* Botones, badges */
--r-sm:   4px;    /* Chips, badges cuadrados */
--r-md:   8px;    /* Tarjetas */
--r-lg:   16px;

Movimiento

--ease:    cubic-bezier(.2, .7, .2, 1);
--ease-io: cubic-bezier(.76, 0, .24, 1);
--t-fast:  .2s;   --t-base: .3s;   --t-slow: .4s;

Sombras

--shadow-sm: 0 4px 12px rgba(0,0,0,.18);
--shadow-md: 0 10px 30px rgba(0,0,0,.28);
--shadow-lg: 0 20px 50px rgba(0,0,0,.35);

11 · Movimiento

Animaciones

Curvas y duraciones consistentes. Se desactivan automáticamente con prefers-reduced-motion.

Clases utilitarias

.anim-in

.anim-up

.anim-up-slow

<div class="anim-up">…</div>

/* Keyframes disponibles */
@keyframes inFade  { from { opacity: 0 } to { opacity: 1 } }
@keyframes inUp    { from { opacity: 0; transform: translateY(24px) } to { opacity: 1; transform: none } }
@keyframes inLine  { from { transform: scaleX(0) } to { transform: scaleX(1) } }
@keyframes kb      { from { transform: scale(1.12) } to { transform: scale(1) } }

/* Respeta reduced motion */
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    transition-duration: .01ms !important;
  }
}

Estructura recomendada de archivos

styles/
├── tokens.css        /* Variables :root — importar primero */
├── reset.css         /* Reset mínimo */
├── typography.css    /* .t-display, .t-h1, .t-body… */
├── buttons.css       /* .btn, .btn-tab, .lang-toggle */
├── cards.css         /* .card, .card-project, .opt, .opt-thumb */
├── forms.css         /* .field, .input, .chip, .day, .range */
├── navigation.css    /* .nav, .nav__links */
├── sections.css      /* .section, .container, .section-head */
├── components.css    /* .fab, .sticky-panel, .compare, .callout */
├── animations.css    /* @keyframes + .anim-* */
└── utilities.css     /* .flex, .gap-*, .mt-* */

main.css  /* importa todo en orden */

Adopción en HTML

<link rel="stylesheet" href="styles/main.css">

<!-- Sección clara: envuelve en .surface--light para que los componentes hereden -->

  <div class="container">

  </div>
</section>
